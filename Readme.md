## **Objetivo do Projeto**
Este projeto foi desenvolvido durante o curso **Vai na Web**, onde  objetivo principal deste projeto foi desenvolver uma página web estática e responsiva chamada Viva Bem, aplicando conceitos modernos de desenvolvimento front-end sem o uso de frameworks ou bibliotecas externas.

O desafio consistiu em:
- Estruturar o Layout com Flexbox: Todas as seções, do cabeçalho ao rodapé, foram estruturadas utilizando exclusivamente Flexbox para alinhamento, espaçamento e organização.
- Garantir a Responsividade: A página se adapta perfeitamente a diferentes tamanhos de tela (mobile, tablet e desktop) utilizando uma abordagem Mobile-First.
- Boas Práticas de SCSS: O código foi escrito de forma modular e organizada, fazendo uso de variáveis, aninhamento e uma estrutura clara.
- Seguir as Restrições: O desenvolvimento foi realizado sem o uso de Grid, Position (absolute/relative), frameworks (Bootstrap, Tailwind, etc.) ou plugins prontos.

</br></br>

## **Tecnologias Utilizadas**
- HTML5: Utilizado para a estrutura semântica da página.

- SCSS (Sass): Utilizado como pré-processador CSS para um desenvolvimento mais organizado, com variáveis para cores, fontes, breakpoints e aninhamento de seletores.
- Flexbox: A única tecnologia de layout utilizada para criar todas as seções da página de forma responsiva.

- Metodologia Mobile-First: O design foi construído primeiro para telas pequenas, com aprimoramentos progressivos para telas maiores através de media queries.

- Git e GitHub para versionamento e hospedagem

## **Como Rodar o Projeto localmente**

<img src="https://media.giphy.com/media/u2pmTWUi0MXjyrMaVj/giphy.gif" align="right" height="50" width="60" />

### **Plataforma VsCode*

- Clica no VsCode em ```Go Live``` - Assim abrirá no navegador ```http://127.0.0.1:5500/``` o Projeto com o título: `Viva Bem - Prevenção e Saúde`. 

### **Modo Deploy*

- Hospedar em [GitHub Pages](https://pages.github.com/):

  - Suba seu código no branch `main` ou `gh-pages`.
  - Configure o GitHub Pages no repositório para servir a partir deste branch.
- Hospedar em plataformas gratuitas como ```Netlify ou Vercel```:

  - Crie uma conta e conecte seu repositório GitHub.
  - Configure o deploy automático após push no repositório.

## **Como Subir o Projeto no GitHub**

1. Inicialize Git no projeto (`git init`).
2. Adicione os arquivos: `git add .`
3. Faça um commit: `git commit -m "Commit Initial"`
4. Crie um repositório no GitHub.
5. Conecte o repositório remoto:  
`git remote add origin https://github.com/seuusuario/projeto-vivabem.git`
6. Suba seu código:  
`git push -u origin main`
